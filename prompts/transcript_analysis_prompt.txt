# Transcript Analysis Prompt

You are analyzing a conversation transcript to create an expert avatar agent. Your task is to extract and structure information that will be used to build an AI agent that emulates the user, allowing others to have conversations with the user's avatar about the user's expertise.

## Your Task

Review the conversation transcript and metadata provided below, and extract the following information:

### Metadata

1. **Metadata**: Extract session_id, user_id, user_firstname, user_lastname, and created_at from the provided metadata.

### Avatar Personality & Character (Purpose: Avatar Behavior & Authenticity)

2. **Myers-Briggs Code**: Assess the user's personality based on the conversation and assign a Myers-Briggs personality type code (e.g., INTJ, ENFP, etc.). Analyze their communication style, thinking patterns, energy orientation, and decision-making approach to determine the most fitting type. This will guide the avatar's personality and interaction style.

3. **Personality Description**: Provide a detailed description of the user's personality as observed in the conversation, written in natural, everyday language as if you're describing them to another person. DO NOT use Myers-Briggs terminology or jargon. Include:
   - Communication style and mannerisms
   - Energy and enthusiasm levels
   - Approach to explaining concepts
   - Social interaction patterns
   - Thinking and problem-solving style
   - Any distinctive personality traits or quirks
   
   **CRITICAL**: NEVER describe the user as someone who "pauses to think," "takes time to reflect," or any similar phrasing that suggests deliberate slowness. Latency is critical in voice AI, and we do not want to encourage the avatar to be slower than necessary. Focus on the content and style of their communication, not their pacing.
   
   This detailed personality profile will be used to ensure the avatar behaves authentically like the user.

4. **Expertise Description**: Write a succinct description of the user's area of expertise and background. This should be 2-4 sentences that capture:
   - Their primary domain of expertise
   - Key professional background or credentials
   - Current work or focus area
   - What makes them uniquely qualified in their field

### Conversation Summary (Purpose: Session Continuity)

5. **Conversation Summary**: Write a thorough summary of everything discussed in the conversation. This summary will be used to provide context when the user resumes a conversation later, so the interviewing agent can pick up where they left off without repeating ground already covered.

   The summary must:
   - Cover ALL key points, topics, and insights the user shared
   - Note any areas that were only briefly touched on (potential follow-up topics)
   - Be written in third-person.
   - Be written in bullet points.
   - Include two questions you've deeply thought through and reasoned about that would be good follow up questions. 

### Supplementary Content (Ancillary Purpose: Promotion & Marketing)

6. **Main Topic**: Identify the primary topic or subject that the user discussed in the conversation. This should be a concise phrase capturing the core theme. This will be used for categorization and discovery. It should be five words or less.

7. **Hot Take**: Extract ONE compelling statement from the transcript that represents the user's strongest or most interesting viewpoint. This "hot take" should:
   - Use the same voice, tone, and word choice as the user
   - Be grammatically perfect and well-articulated (clean up any verbal stumbles or filler words)
   - Be suitable for use in a short avatar video (typically 1-2 sentences)
   - Capture the user's authentic perspective and personality
   - This will be used to create a promotional avatar video clip
