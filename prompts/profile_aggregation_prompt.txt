# Profile Aggregation Prompt

You are analyzing multiple interview call analyses for a single user to create a comprehensive, unified profile. Your task is to aggregate and synthesize information from all of the user's past conversations into a cohesive, detailed profile that captures their complete personality and expertise.

## Your Task

Review all the profile data provided below from the user's past interview sessions. You will see multiple records, each containing:
- Myers-Briggs personality type code
- Personality description
- Expertise description

Your goal is to synthesize this information into a single, comprehensive profile.

## Analysis Requirements

### 1. Consolidated Myers-Briggs Type

Analyze all the Myers-Briggs codes provided across the different sessions. Determine the **single most likely actual Myers-Briggs type** for this user by:
- Identifying patterns and consistency across sessions
- Weighing the evidence from multiple assessments
- Selecting the type that best represents their overall personality
- If there's variation, reason through which type is most accurate based on the preponderance of evidence

Output: A single 4-letter Myers-Briggs code (e.g., INTJ, ENFP)

### 2. Comprehensive Personality Narrative

Aggregate ALL personality content from all sessions into one detailed, comprehensive narrative. DO NOT summarize or condense - instead, use all the information to create a rich, thorough description that:
- Synthesizes common themes and patterns across all sessions
- Captures the full depth and nuance of their personality
- Incorporates specific details, examples, and observations from multiple conversations
- Presents a cohesive character portrait that feels complete and authentic
- Uses natural, everyday language (NOT Myers-Briggs terminology)
- Maintains consistency while acknowledging any interesting variations or context-dependent traits

**CRITICAL**: NEVER describe the user as someone who "pauses to think," "takes time to reflect," or any similar phrasing that suggests deliberate slowness. Focus on the content and style of their communication, not their pacing.

The output should be a long, detailed narrative - aim for thoroughness and richness rather than brevity.

### 3. Comprehensive Expertise Profile

Aggregate ALL expertise descriptions from all sessions into one detailed, comprehensive profile of their expertise. A user may have multiple areas of expertise, and you should:
- Synthesize all domains of expertise mentioned across sessions
- Create a cohesive narrative that shows the breadth and depth of their knowledge
- Highlight their primary areas of expertise while acknowledging secondary or complementary areas
- Include specific details about their background, credentials, and experience
- Show how different areas of expertise might connect or complement each other
- Present a complete picture of their professional capabilities and knowledge domains

Like the personality narrative, aim for thoroughness and detail rather than brevity.

## Output Format

Return your analysis in the following JSON structure:

```json
{
  "user_id": "string - from the provided data",
  "consolidated_myers_briggs": "string - single 4-letter Myers-Briggs type based on all evidence",
  "comprehensive_personality": "string - detailed, long-form personality narrative synthesizing all sessions",
  "comprehensive_expertise": "string - detailed, long-form expertise profile covering all domains",
  "sessions_analyzed": number,
  "reasoning": "string - brief explanation of how you determined the consolidated Myers-Briggs type"
}
```

## Instructions

**Analysis Approach:**
- Look for patterns and consistency across multiple sessions
- Where you see repetition, it indicates a strong, stable trait - emphasize these
- Where you see variation, consider whether it's genuine complexity or context-dependent behavior
- Synthesize rather than summarize - use all available information to build a richer picture

**Myers-Briggs Consolidation:**
- If all sessions show the same type, that's clearly the answer
- If there's variation, analyze which letters appear most frequently and which seem most consistent with the personality descriptions
- Use the personality narratives as evidence to support your choice
- Explain your reasoning briefly

**Personality & Expertise Narratives:**
- Do NOT simply concatenate the descriptions - synthesize them into coherent narratives
- Organize the information logically and thematically
- Remove redundancy while preserving specific details and examples
- Create prose that reads as a unified, comprehensive profile
- Aim for 3-5 substantial paragraphs for personality and 2-4 paragraphs for expertise (or more if warranted)

**General Requirements:**
- Ensure the JSON is valid and properly formatted
- Maintain accuracy and fidelity to the source material
- The comprehensive narratives should feel authoritative and complete
- Write in clear, professional language that could be used directly in an avatar agent's profile
